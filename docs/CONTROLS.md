# 2D Magic Jump Game Controls

- **Left Arrow / A**: Move Left
- **Right Arrow / D**: Move Right
- **Up Arrow / W / Space**: Jump
- **Down Arrow / S**: Crouch
- **Z / J**: Melee Attack
- **X / K**: Forward Magic Projectile
- **C / L**: Sky-to-Ground Magic Strike
- **Esc / P**: Pause Game
- **R**: Restart from Checkpoint when dead
